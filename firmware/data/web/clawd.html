Anthropic token

Paste your Claude Code OAuth access token (from ~/.claude/.credentials.json on Linux or the Claude Code-credentials Keychain item on macOS — the accessToken field).

Console API keys (sk-ant-...) work too but show only developer-tier rate limits, not your Claude Code subscription usage.

Shortcut webhook (optional)

The original Clawdmeter has physical buttons that send keystrokes to the host over BLE HID. This device has no BLE, so shortcuts are forwarded as POST {"key":"<name>"} to a webhook URL of your choice. Run a small helper on your machine (see README) to translate them into real keystrokes.
